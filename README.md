# ⚡ B.L.E.E.D. PROTOCOL (By HOLO EARTH)
**Back-end Legal Evaluation & Expense Diagnostic**

> *YEAR 2026. THE CORPORATE SYSTEM IS BLEEDING CAPITAL. UNTRACKED SERVICE LEVEL AGREEMENTS ARE DRAINING CASH TO VENDORS IN THE SHADOWS.*

B.L.E.E.D. Protocol is an automated, AI-driven forensic procurement tool. It ingests unstructured legal contracts (PDFs) and system outage logs (CSVs), utilizing the ultra-fast **Gemini 3.5 Flash-Lite** model to instantly identify SLA breaches and calculate recoverable vendor penalties.

## 🚀 Features
* **Automated Document Extraction:** Native parsing of `.pdf` master contracts and `.csv` system logs.
* **Deterministic AI Schemas:** Built with Pydantic and Google GenAI SDK to force the LLM into returning strict, mathematically sound JSON data.
* **Cyberpunk Command Dashboard:** Custom dark-mode UI with dynamic neon financial metrics and interactive data evidence tables.
